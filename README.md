# Portfolio — محمد محمودی

رزومه و پورتفولیوی شخصی با **Next.js + TypeScript + Tailwind**.

## اجرا

```bash
cd portfolio
npm install
npm run dev
```

باز کردن: [http://localhost:3000](http://localhost:3000)

## ساختار محتوا

ویرایش متن‌ها و پروژه‌ها بدون دست زدن به UI:

- `src/data/profile.ts`
- `src/data/projects.ts`
- `src/data/skills.ts`
- `src/data/experience.ts`
- `src/data/certificates.ts`

تصاویر: `public/images/profile.jpg` و `public/images/maktab-certificate.jpg`

## صفحات

`/` · `/about` · `/skills` · `/experience` · `/projects` · `/projects/[slug]` · `/certificates` · `/contact`
